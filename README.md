# RottenPotatoes

Catálogo de filmes em Rails.

## Requisitos

- Ruby 3.4.10
- SQLite 3

## Instalação

```bash
bundle install
```

## Banco de dados

```bash
bin/rails db:prepare
bin/rails db:seed
```

## Testes

```bash
bin/rails test
```

## Servidor

```bash
bin/dev
```

Acesse http://localhost:3000/movies.
